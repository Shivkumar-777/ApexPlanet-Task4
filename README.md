# DevPortfolio 🚀

A modern, responsive **personal portfolio website** built using **HTML, CSS, and JavaScript** to showcase skills, projects, and interactive web applications.

---

## 🔥 Features

### 🏠 Home
- Professional hero section
- Clear call-to-action buttons
- Responsive layout

### 💼 Projects
- Project showcase with clean cards
- Modern UI inspired by real-world designs

### 🛍️ Products
- Product listing page
- Filter by category
- Sort by price and rating
- Search functionality
- Dynamic rendering using JavaScript

### ✅ To-Do App
- Add & delete tasks
- Task completion tracking
- Progress bar
- Data persistence using **localStorage**

### 📩 Contact
- Glassmorphism contact form
- Input validation
- Success popup animation
- Stores submitted messages in **localStorage**

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
- LocalStorage API
